# ТЗ заказчика и статус реализации

Документ объединяет запросы из **«ВСЕ ДОРАБОТКИ»** и **«ЗАДАНИЯ + монеты за них»** (исходники — `.docx` в корне репозитория) и фиксирует, что уже есть в коде `mlaffon-tg-app`.

**Обновлять:** при смене требований или после внедрения — править таблицу статусов и раздел «Реализовано».

---

## Глоссарий

- **Монеты / поинты** в документах заказчика смешаны; в продукте — целые награды и балансы (`reward`, `coins`, отдельно Twitch/Kick).
- **Бот** — Telegram-бот; в этом монорепозитории **нет** его исходников (только WebApp + API). Контакты в боте — отдельная зона ответственности.
- **Платформы:** Twitch, Kick, Telegram, мини-приложение.

---

## Часть A. Требования из «ВСЕ ДОРАБОТКИ»

### A1. Карточка эфира (Twitch / Kick)

- Добавить картинку/баннер для стрима.
- Текст и визуал: тема **молнии** — постепенное заполнение по прогрессу стрика; после порога — **свечение**.
- **Критерии приёмки:** согласованный макет; состояния прогресса читаемы; доступность (не только цвет).

### A2. Сплит награды при одной привязанной платформе

- Заказчик: сплит должен работать, **даже если одна платформа не привязана**.
- **Требует уточнения:**  
  - вариант «100% на единственную привязанную платформу» **или**  
  - текущая модель «делим между Twitch/Kick в БД без проверки OAuth».

### A3. Проверка сообщений в чате для заданий

- Цель: засчитывать участие в **чате стрима** для заданий.
- В коде уже есть зачёт через API и БД — это **не** нативная подписка на чат Twitch/Kick; для «настоящей» проверки нужны EventSub/аналог или операторский сценарий.

### A4. Контакты в боте (новый аккаунт)

- Везде в боте — актуальные контакты. В репозитории при необходимости — только ссылки/тексты в WebApp (env, онбординг, справка).

### A5. Предикты: оповещения после итога

- Показывать **сколько баллов** получил/потерял пользователь; явно писать **какой исход победил**; при проигрыше — **минус N** и победивший исход.

### A6. Задания / дропы: UX «Подробнее»

- Убрать путаницу: полная инфа не только через неочевидную кнопку.
- Подсказка: **нажмите на само задание** для деталей; иконка **«?»** вместо лампочки в хинте.

## Часть B. Требования из «ЗАДАНИЯ + монеты за них»

### B1. Кампания BLACK RUSSIA

| Элемент | По заказчику |
|--------|----------------|
| Заголовок блока | BLACK RUSSIA |
| Задание 1 | **550** монет: регистрация по ссылке, 2 скрина (регистрация + в игре: ник, сервер) |
| Ссылка | `https://blackrussia.online/registration?n=mlaffon` |
| Задание 2 | **1250** монет: 5 уровень, скрин (уровень, ник, сервер), семья на стриме |
| Логика | 2-е открывается после 1-го; прогресс **1/2**; после 1-й части — награда и **смена** задания на второе (новый текст/фото, у 2-го ссылки нет) |

### B2. Задания Twitch (и смежные)

1. **300** — подписка на Twitch; при отписке — списание монет.  
2. **500** — подписка на TG-канал с проверкой; при отписке — списание.  
3. **75** — первый заход в приложение.  
4. **200** — привязать Twitch.  
5. Друзья (рефералы) — уже есть; **пожелание:** динамический порог в тексте (3 → 5 → 10 …).  
6. **100** — зайти на стрим и написать в чат.  
7. **600** — 7 стримов подряд; пропуск — сброс.

### B3. Удалить лидерборд

- Убрать из навигации и UI (политика по API — отдельно).

### B4. Игры

- Убрать из **игры** монеты и умножение **визуально** (и уточнить у заказчика: отключать ли колесо/буст в экономике).

### B5. Профиль

- Убрать отдельную строку с уровнем + рангом в лидерборде + множителем; **уровень** показывать **у ника** (справа или в одной строке).

### B6. Прочие правки заданий

- Обсуждалось в кружке Telegram — **контент TBD** до пересылки.

### B7. Розыгрыш

- В админке меняется заголовок; в списке/карточке для пользователя — **отображать заданный заголовок** (заказчик просил акцент на нём); **таймер** сохранить. Референс оформления: кружок с датой/временем.

### C2. Уже есть и хорошо стыкуется с продуктом (без привязки к одному пункту дока)

- Эфир: старт/стоп в админке, `GET` активного эфира, `POST /api/v1/live-broadcast/watch`, WS-события.

- Реферальная программа и недельные бонусы (отдельные сервисы).
