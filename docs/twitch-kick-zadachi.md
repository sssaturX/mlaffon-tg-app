# Twitch и Kick: подключение и идеи заданий

## Стрик «заход на стрим» (отдельно по платформам)

Считается **в UTC-сутках**: для Twitch и для Kick свой счётчик.  
Чтобы день засчитался, пользователь нажимает **«Засчитать»** на главной, когда:

1. **Стрим в эфире** на канале, который вы задали в окружении API.  
2. Аккаунт платформы **подключён** в профиле.  
3. По умолчанию пользователь **подписан** на этот канал (можно отключить: `STREAM_STREAK_REQUIRE_FOLLOW=0`).

Переменные в `apps/api/.env`:

- `TWITCH_STREAM_STREAK_BROADCASTER_LOGIN` — логин канала Twitch (без `#`).  
- `KICK_STREAM_STREAK_CHANNEL_SLUG` — slug канала Kick (как в URL).  

Эндпоинт: `POST /api/v1/stream-streak/claim` с телом `{ "platform": "twitch" | "kick" }`.  
Бонус монет за каждые N дней стрика задаётся в `game.config.json` (`streak.bonusEveryDays`), отдельно для каждой платформы (идемпотентные ключи).

Полное доказательство «смотрел N минут» API Twitch/Kick не дают без своих событий/чата; текущая схема — **эфир + подписка на канал** как практичный сигнал для комьюнити.

## Как подключить Twitch

1. **Регистрация приложения**  
   В [консоли разработчика Twitch](https://dev.twitch.tv/console/apps) создайте приложение. Укажите OAuth Redirect URL **точно так же**, как в API-окружении (ниже).

2. **Переменные в `apps/api/.env`** (скопируйте из `.env.example` в корне репозитория):

   - `TWITCH_CLIENT_ID` — Client ID из консоли  
   - `TWITCH_CLIENT_SECRET` — секрет приложения  
   - `TWITCH_REDIRECT_URI` — например `http://localhost:3001/api/v1/oauth/twitch/callback` для локальной разработки  

   В продакшене замените хост на ваш публичный URL API; тот же URI должен быть добавлен в настройках приложения Twitch.

3. **Публичный URL фронта**  
   `PUBLIC_WEB_URL` — адрес мини-приложения (например `https://your-domain` или локально `http://localhost:5173`). После успешного OAuth пользователь перенаправляется обратно на фронт с параметром успеха.

4. **В мини-приложении**  
   Откройте **Профиль** → блок Twitch → **Подключить**. Откроется страница авторизации Twitch; после согласия аккаунт привязывается к вашему Telegram-пользователю.

## Как подключить Kick

1. **Регистрация OAuth-клиента**  
   Создайте клиент в [документации Kick](https://docs.kick.com) (раздел OAuth). Для Kick используется **PKCE** — это уже учтено в API.

2. **Переменные в `apps/api/.env`**:

   - `KICK_CLIENT_ID`  
   - `KICK_CLIENT_SECRET`  
   - `KICK_REDIRECT_URI` — например `http://localhost:3001/api/v1/oauth/kick/callback`  

   Redirect URI в консоли Kick и в `.env` должны **совпадать посимвольно**.

3. **Опционально**  
   `KICK_API_BASE` — если используется нестандартная база API (по умолчанию `https://api.kick.com`).

4. **В мини-приложении**  
   **Профиль** → Kick → **Подключить**, затем OAuth на стороне Kick.

## Что уже умеет бэкенд (типы проверок в `taskMeta`)

В коде заданий заданы метаданные `meta` (JSON) для платформенных задач:

| Платформа | Проверка в `meta` | Смысл |
|-----------|-------------------|--------|
| Twitch | `helix.kind: "connected"` | Достаточно привязать Twitch |
| Twitch | `helix.kind: "follow"` + `helix.broadcaster_login` | Подписка на канал (логин стримера, без `#`) |
| Twitch | `helix.kind: "subscription"` + `helix.broadcaster_login` | Платная подписка на канал |
| Kick | `kick.kind: "connected"` | Достаточно привязать Kick |
| Kick | `kick.kind: "follow"` + `kick.channel_slug` | Подписка на канал по slug |

Реализация: `apps/api/src/services/taskVerifyLogic.ts`, схема: `apps/api/src/taskMeta.ts`.

## Идеи заданий вокруг стримов (концепты)

Ниже — идеи для геймификации; часть потребует доработки API (например, часы просмотра, события чата).

### Общие для Twitch и Kick

- **Ежедневный вход в мини-приложение** — уже близко к «глобальным» задачам без привязки к платформе.  
- **Подписка на канал автора/партнёра** — уже покрыто `follow`/`subscription` (Twitch) и `follow` (Kick).  
- **Реферальная программа** — пригласи друга по ссылке (логика рефералов в проекте может быть уже частично реализована).  

### Специфично Twitch (Helix)

- Просмотр стрима N минут (нужны события/опросы или интеграция с Drops/аналитикой — усложнённо).  
- Участие в канальном чате (IRC/EventSub — отдельная разработка).  
- Подписка на конкретную категорию игры (если задание на канал с нужной игрой).  
- Клипы / рейды — через расширенные API и правила модерации.  

### Специфично Kick

- Подписка на канал по slug — уже есть проверка follow.  
- Реакции на стрим / «boost» — если в будущем появятся стабильные публичные API под такие действия.  

### Смешанные «оба сервиса»

- **Подключи и Twitch, и Kick** — бонус за линк обоих аккаунтов (в интерфейсе базовая светло-синяя тема совпадает с экраном без OAuth и с экраном, где подключены оба сервиса; отдельно фиолетовый/зелёный — только при одном из них).  
- Разные цепочки заданий: сначала OAuth одной платформы, затем другой, затем награда.
